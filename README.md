# traveltech
SafeRoute — Smart Tourist Emergency Assistant 

Problem Statement:
Foreign tourists may struggle to understand local emergency warnings, identify unsafe areas, and find designated shelters during extreme weather events.

Solution:
SafeRoute is a multilingual web application designed to help tourists access emergency information, understand safety instructions, and locate example shelters on an interactive map.

Features

-  Weather Emergency Dashboard — Displays weather information to support safer travel planning.
-  Multilingual Safety Instructions — Provides safety information in English and Tamil.
-  Interactive Map — Displays shelter markers to help users identify example shelter locations.
-  Alert Source and Timestamp — Helps users understand where an alert originated and when it was recorded.
-  Emergency Contact Information — Provides emergency contact details for quick reference.
-  Data Visualization — Presents relevant information through charts and visual elements.

Technologies Used

- React — Building reusable user interface components.
- Vite — Development server and build tool.
- TypeScript — Type-safe JavaScript development.
- Tailwind CSS — Utility-first styling for a responsive interface.
- Leaflet — Interactive maps and shelter markers.
- OpenStreetMap — Map data and map tiles.
- Recharts — Charts and data visualization.
- Lucide React — Icons for a clear and user-friendly interface.

Installation and Setup

Prerequisites

- Node.js and npm installed on your computer.
- Internet connection for map tiles and any external APIs used by the application.

Steps

1. Clone or download this repository.

2. Open the project folder in VS Code.

3. Install dependencies:
   
   npm install

4. Start the development server:
   
   npm run dev

5. Open the local URL displayed in the terminal, usually "http://localhost:5173".

Production Build

To create a production build, run:

npm run build

To preview the production build locally:

npm run preview

Data and Limitations

- Clearly identify simulated alerts and example shelter locations.
- Example shelter markers must not be treated as verified emergency shelters.
- The application is a demonstration project and does not replace official emergency warnings or instructions from local authorities.
- Do not assume that SOS or emergency features contact authorities unless that capability has been implemented and verified.
- Check official local sources for current emergency information.
